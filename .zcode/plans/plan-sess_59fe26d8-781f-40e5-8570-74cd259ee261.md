# Planogram photo view for the selected-shelf popup

## Context

The shelf view already has a planogram engine: `ShelfDetail.tsx` renders a front elevation of the selected shelf (bays × levels, facings positioned by pin coordinates via `shelfLayout.ts`), used by both the shopper viewer (`ViewerPage.tsx:720`) and the editor shelf preview (`EditorPage.tsx:990`). But facings render only as category-colored boxes with name + price text — product photos (`Product.image_url`, already shown in viewer search results/product sheets and served from `/uploads/...` or data-URLs in try mode) never appear. Goal: when looking at the selected shelf, show the product images on the planogram, while keeping the existing schematic view.

## Changes — all in the frontend, one shared component

### 1. `frontend/src/components/ShelfDetail.tsx` (main work)

- **Two view modes with a small toggle**: `photos` (new photo planogram) and `diagram` (current rendering). The toggle renders only when at least one product on the shelf has `image_url`; default mode = `photos` when images exist, else `diagram`. Override state resets when the shelf changes.
- **Photos-mode geometry**: taller level bands (`PHOTO_LEVEL_H ≈ 112` vs current `LEVEL_H = 58`), boards/dividers/frame drawn at the photo-mode band pitch. Facing display width `max(facingWidth * pxPerM, 44)` so photos are legible (slight neighbor overlap allowed when shelves are dense; draw order keeps left→right stacking sensible).
- **Facing with an image**: subtle category-color backdrop rect (existing style, lower opacity) + SVG `<image href={product.image_url} preserveAspectRatio="xMidYMax meet">` bottom-anchored so the product "stands on the board", plus a caption strip (truncated name, price) in the bottom of the band and a `<title>` tooltip with the full product name. Click → `onPickProduct` unchanged.
- **Facing without an image** (in photos mode): falls back to the current colored rect + name + price rendering, sized to the photo band.
- **Terminology**: modal title becomes `${label} — planogram` (docs already call this popup "the planogram popup"); summary line and bay badges unchanged.
- No props/signature changes; inline styles consistent with the component's current style (no new CSS file needed).

### 2. `frontend/src/components/ShelfDetail.test.tsx`

- Update the title assertion to `— planogram`.
- Add tests: (a) products with `image_url` render `<image>` elements by default in photos mode; (b) the toggle switches back to diagram (and its aria-pressed states); (c) products without images keep the colored-rect fallback; (d) toggle is absent when no product has an image (existing tests' fixtures have no images, so they keep passing with just the title update).

### Explicitly unchanged

- `shelfLayout.ts` (layout engine), backend, API types, viewer/editor call sites — the feature is entirely inside the shared `ShelfDetail` component, so viewer, editor preview, and try-mode (data-URL images) all get it at once. Dark mode unaffected (the SVG drawing surface is fixed beige in both modes today).
